# 🎮 MyFirstGame

My first game created with Python and Pygame.

## 🕹️ About the game

A simple 2D game where the player controls a character and avoids falling enemies.

## 🛠️ Technologies

- Python
- Pygame
- Git
- GitHub

## 🎯 Features

- Player movement
- Falling enemies
- Collision detection
- Score system
- Game over system
